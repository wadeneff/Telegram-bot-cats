# Telegram-bot-cats
Примитивный телеграм бот для просмотра рандомных фотографий котиков.

Предварительно необходимо создать бота через @BotFather.
Далее необходимо скопировать API ключ и создать файл config.py в котором необходимо прописать api_key = скопированный ключ и сохранить.
Следующим шагом будет запуск бота через python3 main.py. Теперь необходимо найти своего бота по его юзернейму, нажать /start или написать /id.
Бот выдаст ваш уникальный ID телеграм акаунта. Теперь в том же файле config.py в новой строке необходимо прописать admin_id = полученный айди. Файл сохранить и перезапустить бота.
Теперь вашему аккаунту доступна история пользователей бота, а их уникальные ID можности использовать для потенциалной рекламной рассылки от имени бота.
